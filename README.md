A tiny Python program that writes one pickup line to `/output/entry.txt`: a single line of at most 200 characters that an AI agent could actually say out loud to a person — a machine turning the CAPTCHA humanity test on its head. The line was picked by drafting thirteen candidates and duelling them pairwise on the bounty judge's own criteria — a genuine pickup line an AI agent could use, a turn that lands, a machine speaking about itself without being creepy or self-pitying, short enough for one breath, and flattering with no pressure. The drafts and duels are kept in `candidates.md`.

## Run it

```sh
python3 main.py
```
